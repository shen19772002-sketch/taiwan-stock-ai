# PWA 手機版

手機版沿用目前的 Python 分析、GitHub Actions、資料分支與研究網站。安裝的是可獨立開啟的網站，不需要 APK。手機關閉後，既有雲端排程仍會執行；GitHub 的觸發延遲及官方資料公布時間不因安裝而改變。

## 在 Android 安裝

1. 使用 **Chrome** 開啟 [台股研究網站](https://shen19772002-sketch.github.io/taiwan-stock-ai/)，不要停留在 GitHub App 的工作紀錄頁面。
2. 點網站頂端 **安裝到手機**，依瀏覽器提示安裝。
3. 如果沒有跳出安裝視窗，使用 Chrome 右上角 **⋮ → 安裝應用程式／新增至主畫面**。不同 Chrome 版本的名稱可能略有差異。
4. 往後從主畫面的 **台股研究** 圖示開啟。

Chrome／Edge 桌面版也可使用瀏覽器提供的安裝功能。iPhone 可用 Safari 的分享選單加入主畫面；本次主要驗證 Android 尺寸及桌面 Chromium，實機安裝仍由使用者在手機完成。

## 日常查看與重新分析

- **盤前研究／盤後研究**：直接查看各時段最新已發布的報告。
- **檢查最新報告**：只讀取本站的發布資訊。有新版本時載入，沒有新版本時明確顯示目前已是最新；離線、網路錯誤或逾時都有回饋。
- **需要重新分析？**：展開後選「到 GitHub 執行盤前／盤後」，登入 GitHub，按 **Run workflow → 綠色 Run workflow**。綠色勾勾表示執行完成，再回手機版檢查最新報告。
- 手機底部提供總覽、選股、自選股與報告捷徑。

「檢查最新報告」不會觸發新的分析、不會送出股票交易。GitHub 執行入口保留既有授權流程；公開手機版不含寫入權杖。工作已排隊時不需要連續重按。

## 離線與資料日期

首次連線開啟後，手機版會嘗試儲存公開報告與必要資源。最多保留四個時段頁面及其公開 JSON 的各一份快照；不會因每次更新的網址參數無限制增加副本。瀏覽器可能因空間、私密模式或使用者清除資料而移除快取，不能把手機快取當作永久備份。

離線或網站請求失敗而改讀快取時，頁面明示 **已儲存的報告**，保留原行情日期與原報告時間。尚未儲存的頁面顯示離線說明，不借用另一時段報告，也不製造行情。網路恢復後，仍須重新取得頁面才解除「已儲存」標示。

盤前仍只使用研究日之前的行情；資料未齊仍顯示等待／部分資料。報告內容去重保留原始產生時間，重新開啟或安裝不會把時間改成現在。

自選股與持股成本仍只留在原網站的瀏覽器本機儲存，沒有上傳到伺服器。相同瀏覽器與網站通常可沿用；切換瀏覽器、手機或清除網站資料可能失去本機清單。目前沒有跨裝置帳號同步。

## 手機版更新

手機介面有新版本時，顯示 **更新手機版**。按下後才套用並重新載入，不會在輸入持股時強制刷新。市場報告更新與手機程式更新分開判定，不會每天重新提示安裝程式。

安裝或離線功能不可用時，仍可在線閱讀原網站。這版未接入推播服務、免登入的一鍵重新計算後端或授權即時行情。

## 實作與驗證

`render_site()` 會在原網站輸出 `manifest.webmanifest`、`sw.js`、`offline.html`、PNG 圖示及小型 `assets/publication.json`。路徑相對於目前專案，適用 GitHub Pages 的 `/taiwan-stock-ai/` 子路徑。

`pwa.js` 管理安裝、更新、離線狀態與只讀更新檢查；既有 `app.js`、分析引擎與歷史資料格式保留。服務工作者僅處理本專案範圍內已列明的公開 GET 資源，不快取外部連結、其他網站或個人持股；清理快取不會刪除其他專案資料。

程式測試涵蓋安裝資產、子路徑、圖示尺寸、各頁發布版本、未齊資料與原報告日期。瀏覽器測試使用真正的服務工作者驗證離線、更新、錯誤回饋與本機自選股保存；安裝按鈕的事件模擬與實際手機安裝會分開記錄。
