在儲存庫目錄，使用已安裝的虛擬環境：

```bash
.venv/bin/python -m pytest -q
.venv/bin/python -m ruff check src tests scripts
node --check src/taiwan_stock_ai/static/app.js
.venv/bin/python -m taiwan_stock_ai check-db
.venv/bin/python scripts/validate_research.py
```

自動測試結果為 **140 passed，0 failed**（包含新增休市與開市日控制流程案例）。Ruff、JavaScript 語法與 `pip check` 均通過。Python 3.12 已本機執行；Python 3.11 是 CI 配置目標，其鎖定依賴已通過相容解析，實跑結果另記於遠端部署紀錄。

瀏覽器驗證需先在另一終端啟動 `.venv/bin/python -m http.server 8000 --bind 127.0.0.1 --directory site`，再執行：

```bash
.venv/bin/python scripts/browser_smoke.py --require-research \
  --screenshots /tmp/taiwan-stock-browser-final
```

驗證既有快照可使用 `run --offline --as-of 2026-10-22`；重新呼叫最新來源時應依來源實際日期選擇研究基準日，不保證未來仍能重建此固定排名。
