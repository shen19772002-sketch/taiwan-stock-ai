## 驗證與資料契約

- `collect(as_of, raw_dir)` 僅取得來源提供的最新資料，**不支援用 as_of 假裝回補歷史行情**。公司名單是當次官方快照，不能用於宣稱無存活者偏差的歷史全市場回測。
- 日期只接受來源明示的西元或民國年月日；無日期、未來日期、非數字、無效 OHLC 及不完整量額會被拒絕。
- 成交量採股數、成交金額採新臺幣。未確認單位的別名不會自動加入。
- 普通股範圍由官方上市／上櫃公司基本資料驗證，排除 ETF、權證、特別股；公司名單取得失敗就暫停該市場行情匯入。
- 原始成功回應與 HTTP 錯誤回應保留為原始 bytes，紀錄 SHA-256、來源 URL、取得時間、來源資料日、接受／拒絕筆數及完整性。連線失敗保存於 manifest，不製造假的行情檔案。
- 日期不明的官方行事曆不會猜成交易日。週末標記休市；明列的官方休市日／開始或最後交易日及當日有效交易行情能確認日曆狀態，其餘工作日維持未知並等待正式行情。農曆春節前最後交易日與春節後開始交易日不會被誤判為休市；僅辦理結算交割的日期是休市。
- 收集器使用 HTTPS 的預設憑證驗證，沒有停用 TLS 驗證或加入網路限制繞過。

上櫃現行歷史請求保留完整 `date`、空白 `id` 及 `response=json` 參數。早期 `/web/stock/aftertrading/daily_close_quotes/stk_quote_result.php` 路徑在本次測試忽略指定日期而回傳最新一天，故程式**不使用該舊路徑**。不會將回傳的最新行情改標為過去日期。

`backfill(start, end, raw_dir)` 逐日請求兩市場官方歷史行情，略過週末，並在每次請求之間至少間隔一秒。只對短暫傳輸錯誤作一次有限重試；連續三次傳輸失敗或無法驗證的有日期資料會暫停該市場，不會繞過拒絕存取。無日期、休市或尚未公布的回應保留為等待資料；來源資料日及表格日期必須與指定日期完全相同。

原始回應以可還原的 gzip 保存，manifest 的 SHA-256 是**未壓縮原始 bytes** 的雜湊。`on_batch` 回呼可讓命令列逐日提交 SQLite；工作中斷前已成功提交的歷史仍保留。`progress` 回呼提供來源狀態與接受／排除筆數。每次回補使用獨立目錄保留證據。

回補以**當次官方公司名單**篩選普通股，用於目前公司的技術指標暖機。它沒有重建過去的上市／下市公司範圍，存在存活者偏差，也未回填過去估值或宣稱產生過去的預測。因此可用於今天的研究，不能當成無未來資訊及無存活者偏差的全市場歷史策略回測。歷史價格保留原始未還原行情，仍受模型文件所述除權息限制。

`tests/test_backfill.py` 使用明確標示的合成 fixtures，驗證真實日期保留、股數／成交額單位、來源日期不匹配拒絕、表格日期衝突、公司名單缺失、週末略過、休市等待、連續失敗暫停、gzip 雜湊與逐日回呼。合成資料不會進入正式回補結果。
