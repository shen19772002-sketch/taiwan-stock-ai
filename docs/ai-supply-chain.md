# AI 供應鏈研究版

研究範圍預設聚焦台灣上市、上櫃的 AI 核心與供應鏈公司。沿用原有官方資料收集、分析引擎、GitHub Actions、資料分支與 PWA；每個納入項目附業務依據與可追溯日期。

## 研究哪些產業

| AI 分類 | 研究方向 |
| --- | --- |
| 晶片與先進製程 | AI 晶片設計、製造及運算相關技術 |
| 先進封裝與測試 | AI／HPC 晶片封裝整合與測試 |
| AI 伺服器 | 伺服器、機櫃與系統整合 |
| 散熱 | AI 伺服器散熱與液冷產品 |
| 電源與備援 | AI 資料中心電源、供電與備援 |
| PCB 與材料 | 高階板、載板及基材 |
| 高速傳輸與光通訊 | 資料中心交換、網路與光傳輸 |
| 記憶體與儲存 | AI 工作負載相關記憶體及儲存 |

這是附證據的研究分類，並非交易所官方產業分類。系統以**市場與股票代號的明確名單**納入，不能因為公司屬於半導體、電子或網通，就自動認定具有 AI 業務；未納入也不代表公司沒有 AI 業務。

首版名單 `2026.10.29.1` 核對 36 家候選，20 家具可驗證的一手來源而啟用，16 家待確認而排除。8 類主要分類均有成分股。廣達、奇鋐尚未完成本版所需的來源核實，暫不納入；這是證據覆蓋限制，不是對其業務作否定判斷。完整啟用條件與證據保存在下述版本化名單中。

名單中的公司可有一個主要分類與多個關聯標籤。產業排行與成交額占比分母只使用本次 AI 範圍，每檔依主要分類計入一次，避免多重標籤重複計算成交額。成交額與占比變化仍屬交易熱度代理指標；只有官方法人資料才稱為法人淨買賣。

## 如何查看手機版

- **AI 個股觀察**：先看各股最新可驗證收盤、行情日、所屬類別及資料狀態。可依類別或代號／名稱搜尋；觀察清單不等於入選排名。
- **資料進度**：首頁用一個狀態區說明本次缺漏；展開「缺哪些資料與研究提醒」查看細節，避免多個警告占滿手機畫面。
- **選股排名**：僅列出通過原有技術、估值及風險條件的 AI 股票，最多 15 檔。資料不足或沒有符合標的時保持空白。
- **個股策略**：保留觀察區間、突破、目標、停損、風險報酬與失效條件；同時可查看分類理由、技術依據與來源。沒有有效策略時不產生價位。
- **我的觀察與歷史報告**：原有自選股、持股成本及報告保留。非 AI 的既有持股也可繼續以可用的官方行情觀察，不會因研究範圍變更而刪除。

「資料待補」與「沒有符合條件」分開判讀。畫面已提供技術資料就緒情形時，不應因為沒有排名就認定必須重新等待 60 個交易日；同日估值尚未公布，也可能使當次無法入選。

## 分類證據與日期

分類名單保存在 [`src/taiwan_stock_ai/data/ai_universe.json`](../src/taiwan_stock_ai/data/ai_universe.json)。每筆保留公司／直接合作方的一手業務來源、標題、理由、確認狀態、擷取摘要及雜湊。僅經驗證且在研究日已可知的證據可啟用成分股。

`known_since` 用來限制分類資訊的可知日期。沒有可驗證歷史發布日期的網頁，只能自實際確認日起使用，不能把今天的 AI 名單當作過去已知的分類。分類版本與雜湊隨新報告保存；新增或調整名單不會改寫以前的報告及預測。目前分類日期的粒度為日，不等同完整的盤中發布時點回測資料庫。

證據確認的是 AI 業務關聯，**不表示 AI 營收占比、純 AI 公司、未來訂單或獲利保證**。連結與內容可能日後變動，分類需定期重新核對。這份明確名單也不等於完整的上市櫃 AI 產業母體。分類名單須經版本化維護；每日行情排程不會自行從新聞新增成分股。

## 自動更新與 PWA

既有盤前、盤後及晚間排程持續使用真實執行入口；晚間重新取得官方行情、估值與法人資料。資料是否補齊仍取決於官方公布及檢查結果，GitHub 實際啟動時間可能延遲。正常排程不會持續輪詢到資料完整，也不會自動回補所有舊日期缺口。

「檢查最新報告」只讀取已發布內容。需要提前重新抓取時，展開「手機版與執行工具 → 需要重新分析？」使用既有 GitHub 盤前／盤後入口。此流程不需要把權杖放進公開網頁。

已安裝的 PWA 若顯示「更新手機版」，按下後套用新版介面。離線副本仍標示原行情日期；尚未儲存的時段不借用其他時段內容。安裝方式見 [PWA 說明](pwa.md)，排程與執行紀錄見 [每日自動化說明](daily-automation.md)。

## 資料與歷史如何保留

資料收集仍保留全市場的官方原始回應與資料庫觀測，分析與新選股才限制在 AI 名單。這樣可保留既有持股行情，也不會刪去原有歷史。`market-data` 仍是永久資料分支，不能刪除或重設。

改版前的全市場報告保留原日期、研究範圍、名單與績效。若介面提供其中 AI 相關股票的範圍檢視，也不會將原始全市場排名重新包裝成當時的 AI 專屬預測。訊號績效可能包含改版前後的不同研究範圍，不能直接宣稱為 AI 專屬回測或超額報酬。

## 開發與相容指令

下列指令沿用現有資料目錄與報告輸出；沒有新增交易功能。

```bash
# 預設研究範圍為 AI 核心與供應鏈
python -m taiwan_stock_ai run --phase postclose

# 明確指定 AI 範圍
python -m taiwan_stock_ai run --phase preopen --scope ai

# 相容模式：以原有全市場範圍產生研究
python -m taiwan_stock_ai run --phase manual --scope all
```

`--scope all` 會產生新的一次全市場研究，並更新相應的最新報告頁；已保存的 AI 報告與其他歷史保持不變。公開排程與免填參數手動入口使用預設 AI 範圍。

分類驗證、日期限制與精確代號篩選由 [`ai_universe.py`](../src/taiwan_stock_ai/ai_universe.py) 管理；[`pipeline.py`](../src/taiwan_stock_ai/pipeline.py) 先保存全市場觀測，再將可用名單交給既有分析引擎。既有交易成本、滑價、資料調整限制與策略條件仍適用。系統僅供投資研究與模擬，不自動執行真實買賣。
